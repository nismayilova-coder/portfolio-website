# nilufarismayilova.com

Personal portfolio site. Plain HTML/CSS, no build step, no framework.

## Structure

- `index.html` — home
- `about.html` — bio, education, languages
- `projects.html` — featured work
- `resume.html` — experience, skills, downloadable resume
- `contact.html` — contact links
- `style.css` — shared styles
- `assets/resume/` — downloadable resume PDF

## Local development

Any static file server works, e.g.:

```bash
python3 -m http.server 5500
```
